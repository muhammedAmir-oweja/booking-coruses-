What the repo already gives you

Ten facts checked against this working tree, not against a tutorial. Half of them delete work you were about to do; the other half are the reason your first attempt will look like it did nothing at all.

Roles exist — enforcement doesn't

users.role is an enum('admin','instructor','student') and User already has isAdmin(), isInstructor(), isStudent(). Nothing to migrate, nothing to add to the model.

Every API route is admin-only today

routes/api.php wraps all of them in ['auth:sanctum', 'admin']. An instructor or student who logs in gets 403 on every endpoint, including /auth/me. The task is splitting that one group, not inventing roles.

The frontend already declares the matrix

Navbar.tsx's DESTINATIONS array and Sidebar.tsx gate every page by role, and AuthContext exposes isAdmin/isInstructor/isStudent. Copy that table into the route groups and the two halves agree by construction.

DevAuthBypass hides all of it

DEV_NO_AUTH=true signs every request in as the first admin row. Your role rules, policies and 403s are invisible until you flip DEV_NO_AUTH=false in Back End/.env and VITE_DEV_NO_AUTH=false for the SPA.

Nothing is throttled at all

Checked in the installed framework: the api group only gets a throttle: entry when throttleApi() is called in bootstrap/app.php — and it isn't. Login is unlimited too. AppServiceProvider::boot() is an empty body: that is where the limiters go.

Mail and queue are already on safe local drivers

MAIL_MAILER=log — every mail renders into storage/logs/laravel.log, no SMTP account needed. QUEUE_CONNECTION=database with the jobs table migrated — so anything ShouldQueue sits in jobs doing nothing until php artisan queue:work runs.

A cookie queued on an API route is dropped

statefulApi() is on, but Sanctum only runs the cookie/session middleware when the request Origin is in sanctum.stateful — which defaults to localhost, localhost:3000, 127.0.0.1, 127.0.0.1:8000, ::1. Vite serves from localhost:5173, and config/app.php has no url key to add it. Task 26 starts with one .env line.

Three tasks are half-built, and the halves do nothing

The capacity helper is written and autoloaded but no controller calls it; BookingCreated is the artisan stub; SetLocale is a generated pass-through that was never registered. All three look done in a file listing and have never run. The first three sections are only the missing halves.

Nothing is localized, and there is almost no Blade

lang/en is published, there is no lang/ar, and 12 API messages are hardcoded English strings. The only Blade file is welcome.blade.php — so localization is __() for the API plus react-i18next for the SPA, and the mail task adds the first real template.

Student isn't notifiable, courses have no files

Student has no Notifiable trait (User does), so it cannot receive a database notification as-is. And courses has no file column — task 25 needs a new table. student_documents is the shape to copy, and its flat world-readable folder is the thing task 25 is reacting to.

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class EnsureUserHasRole
{
    /**
     * Usage: ->middleware('role:admin') or 'role:admin,instructor'.
     * Always sits behind auth:sanctum - it authorizes, it does not authenticate.

    public function handle(Request $request, Closure $next, string ...$roles): Response
    {

        }

class AppServiceProvider extends ServiceProvider

    public function boot(): void

        // Bookings: the real target. Keyed by user id so one noisy account cannot
        // lock out everyone behind the same NAT - and in dev that is you.
        RateLimiter::for('bookings', function (Request $request) {
            return Limit::perMinute(5)
                ->by($request->user()?->id ?: $request->ip())
                ->response(fn () => response()->json([
                    'message' => __('errors.too_many_bookings'),

        // guessing one account from many hosts and many accounts from one host
        // are both limited.

            return [
                Limit::perMinute(5)->by('email:'.(string) $request->input('email')),
                Limit::perMinute(20)->by('ip:'.$request->ip()),
            ];
        });

        // File uploads: few per minute, they are expensive and large.
        RateLimiter::for('uploads', fn (Request $request) => Limit::perMinute(10)

        // because the dashboard fires several requests per page.

                ? Limit::perMinute(240)->by($request->user()->id)

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Http\Requests\StoreCourseFileRequest;
use App\Models\Course;
use App\Models\CourseFile;
use Illuminate\Http\JsonResponse;
use Illuminate\Support\Facades\Gate;
use Illuminate\Support\Facades\Storage;
use Symfony\Component\HttpFoundation\StreamedResponse;

class CourseFileController extends Controller
{
    private const DISK = 'course_files';

    public function index(Course $course): JsonResponse
    {
        Gate::authorize('view', $course);

        $files = $course->files()->latest()->get()->map(fn ($f) => $this->format($f));

        return response()->json($files);
    }

    public function store(StoreCourseFileRequest $request, Course $course): JsonResponse
    {
        // Only the owning instructor (or an admin) may add to this course.
        Gate::authorize('update', $course);

        $file = $request->file('file');
        $category = $request->validated('category', 'material');

        // store() hashes the name for us, which is what keeps a hostile
        // original_name out of the filesystem. The folder is the organization.
        $path = $file->store("course-{$course->id}/{$category}", self::DISK);

        $record = $course->files()->create([
            'uploaded_by' => $request->user()->id,
            'original_name' => $file->getClientOriginalName(),
            'path' => $path,
            'disk' => self::DISK,
            'category' => $category,
            'mime_type' => $file->getMimeType(),
            'size' => $file->getSize(),
        ]);

        return response()->json($this->format($record), 201);
    }

    public function download(Course $course, CourseFile $file): StreamedResponse
    {
        Gate::authorize('view', $course);

        // Nested binding does not verify the parent: /courses/1/files/99 resolves
        // file 99 even if it belongs to course 2. Check it, like
        // StudentDocumentController::destroy() already does.
        abort_unless($file->course_id === $course->id, 404);
        abort_unless(Storage::disk($file->disk)->exists($file->path), 404);

        // Streams from outside the webroot, and restores the real filename.
        return Storage::disk($file->disk)->download($file->path, $file->original_name);
    }

    public function destroy(Course $course, CourseFile $file): JsonResponse
    {
        Gate::authorize('update', $course);
        abort_unless($file->course_id === $course->id, 404);

        // Disk first, row second: a missing file with a surviving row is a
        // broken download, a missing row with a surviving file is a leak.
        Storage::disk($file->disk)->delete($file->path);
        $file->delete();

        return response()->json(['message' => __('files.deleted')]);
    }

    private function format(CourseFile $f): array
    {
        return [
            'id' => $f->id,
            'course_id' => $f->course_id,
            'original_name' => $f->original_name,
            'category' => $f->category,
            'mime_type' => $f->mime_type,
            'size' => $f->size,
            'download_url' => $f->downloadUrl(),
            'uploaded_at' => $f->created_at,
        ];
    }
}

use App\Http\Controllers\Controller;

use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Cookie;

class PreferenceController extends Controller
{
    private const COOKIE = 'prefs';
    private const ONE_YEAR = 60 * 24 * 365;   // minutes, not seconds

    private const DEFAULTS = [
        'locale' => 'en',
        'theme' => 'light',
        'sidebar_collapsed' => false,
        'per_page' => 10,
    ];

    public function show(Request $request): JsonResponse
    {
        return response()->json($this->read($request));
    }

    public function update(UpdatePreferencesRequest $request): JsonResponse
    {
        // Merge, do not replace: the SPA sends only what changed.
        $prefs = [...$this->read($request), ...$request->validated()];

        Cookie::queue(Cookie::make(
            name: self::COOKIE,
            value: json_encode($prefs),
            minutes: self::ONE_YEAR,
            path: '/',
            domain: null,
            secure: $request->secure(),
            // httpOnly MUST be false: the React app reads this one directly, so
            // it never has to wait for a round trip to paint the right theme.
            httpOnly: false,
            raw: false,
            sameSite: 'lax',
        ));

        return response()->json($prefs);
    }

    /**
     * A cookie is client input: a hand-edited value must not blow up the app,
     * so anything unparseable falls back to the defaults.
     */
    private function read(Request $request): array
    {
        $raw = json_decode((string) $request->cookie(self::COOKIE, '{}'), true);

        return [...self::DEFAULTS, ...(is_array($raw) ? $raw : [])];
    }
}

      ?.slice('prefs='.length)

    if (!raw) return DEFAULT_PREFS

    // Laravel url-encodes the JSON on the way out.
    return { ...DEFAULT_PREFS, ...JSON.parse(decodeURIComponent(raw)) }
  } catch {
    // Malformed or hand-edited cookie: defaults, never a crash.
    return DEFAULT_PREFS
  }
}

/** Optimistic local write, so the UI turns over before the request lands. */
export function writePrefsCookie(prefs: Prefs): void {
  const value = encodeURIComponent(JSON.stringify(prefs))
  const year = 60 * 60 * 24 * 365
  document.cookie = `prefs=${value}; path=/; max-age=${year}; samesite=lax`
}

export function PreferencesProvider({ children }: { children: React.ReactNode }) {
  // Initialised from the cookie, so the very first render is already right.
  const [prefs, setPrefs] = useState<Prefs>(readPrefs)

  const update = useCallback(async (patch: Partial<Prefs>) => {
    const next = { ...prefs, ...patch }

    // Local first: the toggle must not wait on the network.
    setPrefs(next)
    writePrefsCookie(next)

    try {
      // Server-side copy, so __() and SetLocale agree with the UI.
      await client.put('/preferences', patch)
    } catch {
      // The cookie is already written; a failed sync is not worth a toast.
    }
  }, [prefs])

  useEffect(() => {
    // data-theme and dir are what the stylesheet actually reads.
    document.documentElement.dataset.theme = prefs.theme
    document.documentElement.lang = prefs.locale
    document.documentElement.dir = prefs.locale === 'ar' ? 'rtl' : 'ltr'
  }, [prefs.theme, prefs.locale])

  return (
    <PreferencesContext.Provider value={{ prefs, update }}>
      {children}
    </PreferencesContext.Provider>
  )
}
